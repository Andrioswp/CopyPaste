# CopyPaste — история буфера обмена для macOS

Приложение живёт **только в меню-баре**: отдельного окна у него нет. По горячей клавише
(по умолчанию **⌘⇧V**) или по клику на иконку в меню-баре у курсора мыши появляется
стеклянная панель с историей копирований.

Написано на Flutter (Dart) + нативный слой на AppKit/Swift: настоящий Liquid Glass
(`NSGlassEffectView`, macOS 26+) с откатом на `NSVisualEffectView`, `NSPasteboard`,
Carbon-хоткеи и синтез ⌘V через `CGEvent`.

## Что умеет

- **История буфера**: текст, форматированный текст (RTF), изображения, скопированные файлы и папки.
- **Вставка** — клик по записи или ⏎: элемент кладётся в буфер и автоматически вставляется
  в приложение, которое было активным до открытия панели.
- **Поиск** по истории прямо в панели, навигация ↑↓, `⌘1…9` — быстрая вставка по номеру.
- **Закрепление** (булавка, `⌘P`) — закреплённые записи всегда сверху и не удаляются при очистке.
- **Удаление** — корзина на строке или `⌘⌫`.
- **Показывает 10 последних записей**, остальное — прокруткой колесом.
- **Миниатюры** изображений и скопированных файлов-картинок.
- **Настраиваемая горячая клавиша**, в том числе с клавишей **Fn** (например `Fn+V` или один `Fn`).
- **Автозапуск** при входе в систему, **тема панели** (системная/светлая/тёмная),
  **стиль стекла** (Liquid Glass / классический blur), лимит хранения (100/500/1000/∞).
- Панель можно **перетаскивать** за шапку; клик по прозрачной рамке вокруг неё закрывает.
- Пароли и «concealed»-содержимое из менеджеров паролей в историю не попадают.

## Сочетания клавиш

| Клавиши | Действие |
|---|---|
| `⌘⇧V` (настраивается) | открыть/закрыть панель у курсора |
| `↑` `↓` | выбор записи |
| `⏎` | вставить выбранное |
| `⌘1…9` | вставить запись по номеру |
| `⌘P` | закрепить/открепить |
| `⌘⌫` | удалить запись |
| `⌘,` | настройки |
| `esc` | очистить поиск → закрыть панель |

## Разрешение «Универсальный доступ»

Без него macOS запрещает синтезировать нажатие ⌘V, поэтому автовставка работать не будет
(это ограничение системы, так же устроены все менеджеры буфера).

1. Запусти приложение — оно само покажет системный запрос.
2. *Системные настройки → Конфиденциальность и безопасность → Универсальный доступ* → включить **CopyPaste**.
3. Если CopyPaste уже в списке, но не работает — удалить кнопкой «−» и добавить заново.

> Приложение подписано ad-hoc, поэтому **после каждой пересборки разрешение нужно выдавать заново**:
> система привязывает его к подписи конкретной сборки. У сборок с сертификатом разработчика
> такой проблемы нет.

## Сборка и установка

Одной командой — сборка, подпись сертификатом и установка в `/Applications`:

```bash
./scripts/build_and_install.sh
```

Вручную:

```bash
flutter build macos --release
ditto build/macos/Build/Products/Release/CopyPaste.app /Applications/CopyPaste.app
```

## Подпись (важно для разрешения)

macOS привязывает разрешение «Универсальный доступ» к подписи приложения. При **ad-hoc**
подписи она меняется после каждой сборки, и разрешение приходится выдавать заново — именно
поэтому приложение подписано локальным самоподписанным сертификатом: тогда разрешение
остаётся действующим между пересборками.

Сертификат создаётся один раз (`signing/cert.pem` и `signing/key.pem` не коммитятся):

```bash
cd signing
openssl req -x509 -newkey rsa:2048 -keyout key.pem -out cert.pem -days 3650 -nodes \
  -subj "/CN=CopyPaste Local Signing/O=CopyPaste" \
  -addext "basicConstraints=critical,CA:FALSE" \
  -addext "keyUsage=critical,digitalSignature" \
  -addext "extendedKeyUsage=critical,codeSigning"
security import cert.pem -k ~/Library/Keychains/login.keychain-db -T /usr/bin/codesign
security import key.pem -k ~/Library/Keychains/login.keychain-db -T /usr/bin/codesign -P ""
security add-trusted-cert -r trustRoot -p codeSign -k ~/Library/Keychains/login.keychain-db cert.pem
```

Проверка: `security find-identity -v -p codesigning` должен показать
`"CopyPaste Local Signing"` **без** пометки `Invalid Key Usage for policy`.

Иконка приложения рисуется скриптом (Pillow). Сейчас установлен вариант **L** —
«карточка на синем» (плоская иконка: синяя плитка, белая карточка истории с синими строками).

```bash
# посмотреть все варианты рядом → preview/icon_variants.png
python3 scripts/make_app_icon.py --sheet

# поставить другой вариант (A…L) и пересобрать приложение
python3 scripts/make_app_icon.py --variant J --install
flutter build macos --release
```

Варианты: `A` синий градиент · `B` светлое стекло · `C` тёмный неон · `D` минимал ·
`E` стопка карточек · `F` плоский синий · `G` плоский контур · `H` плоский + стопка ·
`I` белый на синем · `J` карточка на белом · `K` карточка на светлом · `L` карточка на синем.

## Диагностика

Нативные события пишутся в `debug.log`: запуск, показ/скрытие панели, клики, обращения UI
к системе, вставка и её цель. Полезные строки: `ui: pointer down`, `ui → paste`, `posted ⌘V`,
`trusted=` (выдано ли разрешение).

Переменные окружения для отладки:

| Переменная | Действие |
|---|---|
| `COPYPASTE_SHOW_PANEL=1` | показать панель сразу при запуске |
| `COPYPASTE_SELFTEST=1` | показать панель и отправить в неё синтетический клик |

Превью интерфейса (рендер без запуска приложения, картинки кладутся в `preview/`):

```bash
flutter test test/preview_test.dart
```

## Ограничения

- Хранится до 500 записей по умолчанию (настраивается), текст до 2 МБ, картинки до 16 МБ.
- Приложение не нотаризовано: при первом запуске на другом Mac система может предупредить
  о неизвестном разработчике.
- Позиция перетащенной панели не запоминается — при следующем открытии она снова появится у курсора.
